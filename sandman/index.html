Autonomous agent teams · dusk

It builds while you sleep.

SANDMAN orchestrates a team of AI agents through a gated pipeline — plan, review, build, ship, deploy — and refuses its own work until an oracle it did not write says otherwise. It sprinkles ideas; you wake up to shipped code.

01 / the night shift · 23:00

Five hands pull one thread.

A planner decomposes the brief into a task graph, then a team of metered builders works it in concurrent waves — each on your key, each under a spend cap, each streaming its actions to a live dashboard. One command starts the night.

The governing law

Autonomy is bounded by verifiability. Where a task has a cheap, objective, ungameable oracle, the loop runs it to green unattended. Where judgment is required — is this UX good, is this production change safe — it stops at a human gate. No referee, no team.

02 / oracle forge · 02:14

It writes the test it must pass — then makes it harder.

You never write test code. You write a Napkin — six plain-English prompts. SANDMAN translates it into a technical oracle, drafts it to a strength floor, then a Nightmare/Warden adversarial layer hardens it into something a builder cannot game.

The oracle is the product. Model capability, the agent loop, the CLI — all copyable. What is hard-won is turning a vague brief into a strong, ungameable fitness function, and refusing to reward code that only looks right.

The forge sets a mutation-tested strength floor; the Nightmare/Warden layer probes for valid-but-weak oracles and seals the gaps. Across a five-gap-class evaluation of deliberately weak oracles, held-out kill-rate lifted from 0.00 to roughly 0.96.

And when a builder returns green-but-wrong, the gate says no. In a real brownfield run the builder returned a passing status for an unknown input; the gate refused the build four times and never shipped it. REFUSED is not a failure of the system — it is the system.

Refused, on purpose

A held-out check the builder never sees runs beside the gate. When it disagrees with a “pass,” the reward-hack is caught — every time it has occurred.
